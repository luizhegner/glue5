# Touch control icons

Chosen one by one (2026-10-17) from several icon sets, each rendered white on
transparent, 128 px square, cropped to its ink and fitted to the same optical
size (its longest side ~100 px; long thin ones a little larger, a few nudged by
eye). The sets' licenses are credited in the app's Credits page.
